# Perfect Number Analyzer in C++

A modular C++ program that identifies perfect numbers by evaluating their proper divisors. The lab separates reusable number-analysis logic from the program entry point.

## Highlights

- Determines whether an integer is a perfect number
- Uses functions split across header and implementation files
- Exercises loops, arithmetic reasoning, validation, and formatted output
- Built as a Visual Studio C++ project

## Key Files

| File | Purpose |
| --- | --- |
| `LAB1_Perfect_Numbers.cpp` | Program entry point and test flow |
| `module.h` | Function declarations |
| `module.cpp` | Perfect-number logic |
| `LAB1_Perfect_Numbers.sln` | Visual Studio solution |

## Skills Demonstrated

C++, modular programming, header/source separation, algorithm design, debugging, and test-driven verification.
